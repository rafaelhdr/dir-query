This is a practice project, running on free API keys. That means it might be slow, and can occasionally fail to respond at all.

If you'd like a more reliable instance for your own use, the project can be replicated with your own API keys to keep it running well for other applications. It's a small, self-contained docker compose setup, so it's easy to install in your own cloud. Source and self-hosting instructions: github.com/rafaelhdr/dir-query.
