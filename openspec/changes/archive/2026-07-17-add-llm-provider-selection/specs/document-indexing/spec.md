## MODIFIED Requirements

### Requirement: Indexing uses a configurable embedding provider, defaulting to a local model requiring no external API credentials
The system SHALL generate embeddings for indexed document content using
whichever embedding provider is configured via `EMBED_PROVIDER` (see the
`llm-provider-selection` capability). By default (`EMBED_PROVIDER` unset or
`cpu`), this SHALL be a locally-run embedding model, requiring no external
API key.

#### Scenario: Indexing succeeds without any credentials configured, using the default provider
- **WHEN** the backend indexes an uploaded PDF while `EMBED_PROVIDER` is
  unset (or `cpu`) and no MiniMax or Gemini API key is configured
- **THEN** indexing completes successfully, since the default embedding
  provider does not depend on any external API

#### Scenario: Indexing using the Gemini embedding provider
- **WHEN** the backend indexes an uploaded PDF while `EMBED_PROVIDER=gemini`
  and a valid `GOOGLE_API_KEY` is configured
- **THEN** indexing completes successfully, using embeddings generated by
  the Gemini embeddings API
